# PuttVision Screen v0.4 ULTIMATE Alpha

스마트폰 한 대를 퍼팅 런치모니터처럼 사용하고, HDMI TV에는 가상 그린/게임 화면을 띄우는 Android 프로젝트입니다.

## v0.4에 들어간 것

### 1) 완전자동 플레이 루프
- 앱 시작
- QR 4개 자동 캘리브레이션
- AUTO ON이면 자동으로 PRECISION READY
- 공이 움직이면 임팩트 감지
- 임팩트 후 고속 프레임 자동 캡처 종료
- 자동 분석
- TV에서 가상공 발사
- 결과가 끝나면 자동 다음 샷 대기
- 8초 동안 공을 치지 않으면 자동 재대기

즉 최초 설치/캘리브레이션 이후에는 매 샷마다 앱 버튼을 누를 필요가 없도록 구성했습니다.

### 2) 240 / 120fps Precision
우선순위:
1. 240fps fixed
2. 120fps fixed
3. 기타 HFR
4. HFR이 안 되면 일반 실시간 분석

고속 CameraX VideoCapture 영상의 실제 프레임을 다시 읽어 분석합니다.
Preview는 임팩트 트리거 용도이며 정밀 수치의 원본이 아닙니다.

### 3) 측정 항목
- Ball speed
- Launch angle
- Head speed
- Face angle
- Path angle
- Face-to-Path
- Smash 근사
- 힐/토 방향 임팩트 오프셋 근사
- 백스윙 시간
- 다운스윙 시간
- Tempo ratio
- 백스윙 길이
- 최대 헤드 가속도 근사
- 측정 confidence

### 4) 매트 마찰 자동보정
고속 프레임에서 공의 속도 감소를 추적해:
- 실제 매트 감속도 추정
- Stimpmeter-equivalent 매트 값 근사
- 약 10cm 이후에 측정된 볼스피드를 임팩트 시점으로 역산

주의: 이것은 물리 매트의 진단/보정용 추정값이며 실제 골프장 그린 스팀프와 동일하다는 의미는 아닙니다.

### 5) 240fps 임팩트 리플레이
샷 직후 폰 화면에:
- 임팩트 전후 고속 프레임 슬로 리플레이
- FACE
- PATH
- BALL SPEED
를 겹쳐서 표시합니다.

TV에서는 동시에 가상공이 굴러갈 수 있습니다.

### 6) Perfect Stroke Score
0~100 종합점수:
- Face
- Path
- Tempo
- Impact
- Distance
- Consistency

TV에 각 하위점수와 총점을 표시합니다.

### 7) 로컬 코치 진단
인터넷/클라우드 없이 현재 측정값과 최근 패턴을 보고:
- 페이스 오픈/클로즈
- 패스 좌우 편차
- 힐/토 정타 편차
- 템포 불안정
- 반복적인 좌/우 미스
등에서 가장 우선순위 높은 교정 포인트 하나를 표시합니다.

현재는 규칙 기반 로컬 코치입니다.
실제 LLM/딥러닝 코치라고 속여 표시하지 않습니다.

### 8) 그린 리딩 UI
TV:

그린 리딩 숫자는 UX용 근사이며 물리엔진과 별개입니다.

### 9) 게임 모드

거리/경사 자동 생성, 점수, 스트릭, 게임 진행상태가 TV에 표시됩니다.

### 10) 기록 / 히트맵

- 최근 Perfect Score

### 11) TV / 폰 역할

- 측정 수치

## 마커

### A. 가장 안정적인 방식
동봉된 `markers/PuttVision_Markers_A4.png` 사용.

### B. v0.4부터 일반 QR 스티커 4개도 지원
시중에 파는 서로 다른 QR 코드 스티커 4개도 캘리브레이션용으로 사용할 수 있게 fallback을 추가했습니다.

배치 조건:
- 좌우 QR 중심간: 45cm
- 앞뒤 QR 중심간: 100cm
- 카메라는 공/퍼터 쪽 뒤에서 목표 방향을 바라보는 기존 설치 방식

앱은 4개 QR의 사각형을 읽어 가까운 쪽/먼 쪽을 원근으로 판단합니다.

중요:
- 일반 QR 코드 스티커는 지원
- ArUco/AprilTag 산업용 마커는 현재 ML Kit QR 스캐너에서 직접 읽지 않음
- ArUco를 꼭 쓰려면 OpenCV/ArUco detector를 별도 추가해야 함

## 퍼터 헤드 마커
퍼터 윗면:
- 힐: 형광 주황 원형 스티커 12~18mm
- 토: 형광 파랑 원형 스티커 12~18mm

두 점:
- 방향 -> Face angle
- 중점 이동 -> Head path / speed

## 현재 중요한 한계
이 프로젝트는 실제 사용자 기기/매트에서 튜닝하기 전 Alpha입니다.

코드에 기능을 넣었다는 것과 상용 런치모니터 수준의 측정오차를 검증했다는 것은 다릅니다.

실제 첫 테스트에서 확인해야 할 것:
1. 기기 CameraX가 240fps 또는 120fps 프로파일을 실제 노출하는지
2. HFR 영상에서 QR이 충분히 선명한지
3. 주황/파랑 퍼터 마커가 조명에서 안정적으로 분리되는지
4. 공 추적 threshold
5. 임팩트 감지 threshold
6. HFR 프레임 디코딩 시간
7. 매트 감속도 추정 노이즈
8. HDMI가 secondary Presentation display로 잡히는지
