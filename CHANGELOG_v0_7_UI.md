# PuttVision v0.7 UI

- Phone UI rebuilt into a compact screen-golf controller layout.
- Camera area remains large; black letterbox area is reused as a status HUD.
- AUTO / Auto Cal / Precision promoted to primary controls.
- Mode / Stats / Settings moved to a compact secondary row.
- Green speed, distance and slope controls are collapsed by default.
- TV scene gets a darker course horizon and deeper green presentation.
- Measurement, HFR, physics and deploy logic are unchanged.

This is an original PuttVision interface inspired by modern screen-golf ergonomics; it does not copy proprietary Friends Screen assets.
