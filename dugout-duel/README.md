# DUGOUT DUEL

2명이 같은 야구 커리어 시간선을 공유하는 모바일 우선 웹게임 프로토타입.

## 현재 구현

- 고3 선수 생성: 이름 / 등번호 / 포지션 / 플레이스타일 / 희망 구단
- 10자리 비공개 방 코드 생성 및 초대 링크
- 최대 2명 입장, 진행 상태 Supabase 영구 저장
- 매주 각자 훈련 선택 후 둘 다 제출되면 서버에서 동시에 결과 계산
- 상대가 먼저 제출한 훈련 종류는 공개하지 않음
- 시즌 타율 / HR / RBI / H / G / WAR, 능력치, 컨디션, 주간 맞대결 승수
- 12주 단위 시즌
- 첫 시즌은 고3 쇼케이스, 종료 후 성적에 따라 드래프트 등급 결정 및 프로 진입
- 이후 프로 연차 / 커리어 누적 기록 / 시즌 히스토리 유지
- localStorage에는 방 코드/참가 토큰만 저장하고 실제 게임 상태는 DB가 보유

## 실행

`dugout-duel/` 폴더를 정적 웹서버로 열면 된다.

예시:

```bash
cd dugout-duel
python -m http.server 8080
```

그 뒤 `http://localhost:8080` 접속.

## 백엔드

현재 연결된 Supabase 프로젝트에는 `dugout_rooms`와 `dugout_*` RPC가 이미 설치되어 있다. 테이블 직접 접근은 anon/authenticated에서 revoke했고, 클라이언트는 검증된 RPC만 호출한다. 공개 클라이언트에는 publishable key만 들어가며 service role key는 사용하지 않는다.
